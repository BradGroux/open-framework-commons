# Changelog

All notable changes to Open Framework Commons are recorded here.

## [1.1.0] - 2026-08-22

### Added

- Recognized Focus Operating Framework as the fifth independent product in
  Commons scope through [Decision 0001](decisions/0001-recognize-focus-operating-framework.md).
- Added a machine-readable `VERSION` file and citation metadata.
- Added contribution, conduct, security, ownership, issue, and pull-request
  guidance for public participation.
- Added repository validation for release metadata, local links, scoped-product
  references, Mermaid fences, and publication hygiene.

### Corrected

- Replaced the obsolete Commons v1.0.0 adoption pin in the review index with
  the exact commit currently peeled from the annotated tag.
- Connected the visualization candidate review to its squash-merged commit.
- Clarified that the 2026-08-02 draft review reports are point-in-time records,
  not current status statements.

### Repository

- Added GitHub topics for public discoverability.

## [1.0.0] - 2026-08-03

### Added

- Published the initial shared principles, boundaries, evidence expectations,
  governance, context, and ecosystem relationship guidance.
- Published sanitized independent review records and visual guides.
- Recorded stable adoption links for the four products in the initial scope.
