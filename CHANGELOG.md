# Changelog

All notable changes to Open Framework Commons are recorded here.

## [2026.09.05] - 2026-09-05

### Changed

- Began YYYY.MM.DD calendar editions with optional same-day correction suffixes; preserved all prior version identities.
- Clarified contribution, legitimate help, privacy, consent and responsible disengagement boundaries.
- Defined bounded conflict resolution, material evidence/applicability dispositions, content compatibility and adoption with deviations.

### Added

- Decision 0002, fictional content/process review cases and a reusable release procedure.
- Parser-based public-inventory Markdown validation, calendar/CFF/release metadata checks, redacted publication scanning and isolated regression tests.
- Locked development tooling, diagram compilation, dependency update configuration and bounded read-only CI.
- Exact-repository release identity/body verification with explicit historical limitations.

### Operations

- Protected published tags, required validation before main changes, and enabled immutable future releases through repository settings.
- Resolved the content/process and repository audit findings without changing downstream adoption records or historical reviews.

## [1.1.0] - 2026-08-22

### Added

- Recognized Focus Operating Framework as the fifth independent product in
  Commons scope through [Decision 0001](decisions/0001-recognize-focus-operating-framework.md).
- Added a machine-readable `VERSION` file and citation metadata.
- Added contribution, conduct, security, ownership, issue, and pull-request
  guidance for public participation.
- Added repository validation for release metadata, local links, scoped-product
  references, Mermaid fences, and publication hygiene.

### Corrected

- Replaced the obsolete Commons v1.0.0 adoption pin in the review index with
  the exact commit currently peeled from the annotated tag.
- Connected the visualization candidate review to its squash-merged commit.
- Clarified that the 2026-08-02 draft review reports are point-in-time records,
  not current status statements.

### Repository

- Added GitHub topics for public discoverability.

## [1.0.0] - 2026-08-03

### Added

- Published the initial shared principles, boundaries, evidence expectations,
  governance, context, and ecosystem relationship guidance.
- Published sanitized independent review records and visual guides.
- Recorded stable adoption links for the four products in the initial scope.
