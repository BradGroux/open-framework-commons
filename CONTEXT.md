# Open Framework Commons Context

Open Framework Commons is the shared language context for a small ecosystem of independent documentation products.

## Language

**Framework**:
A documented set of principles, boundaries, and practical guidance that people and agents consult while accomplishing a class of tasks or goals.
_Avoid_: Application, runtime, operating system, software platform

**Open Framework Ecosystem**:
AI-Native Operating Framework, Influence Operating Framework, AI Dev Days, Relationship Operating Framework, and the Commons documentation they share.
_Avoid_: Suite, monolith, platform

**Open Framework Commons**:
The small canonical collection of principles and boundaries shared by every ecosystem product.
_Avoid_: Parent framework, base system, interoperability layer

**Independent product**:
An ecosystem product with its own purpose, audience, guidance, authority, and evolution.
_Avoid_: Module, child framework

**Shared principle**:
A durable belief that should guide all four ecosystem products while allowing different local methods.
_Avoid_: Universal workflow, implementation requirement

**Product-local guidance**:
The methods, examples, research, Mission Control recommendations, and decisions owned by one product.
_Avoid_: Commons requirement

**Mission Control**:
Product-local, stack-agnostic guidance for making purpose, health, research, contributions, actions, and approvals visible to an adopter.
_Avoid_: Required application, shared dashboard

**Adoption**:
A product's explicit decision to reference a Commons revision while preserving its own authority and independence.
_Avoid_: Certification, inheritance, automatic migration
