# Decision 0001: Recognize Focus Operating Framework

- **Status:** Accepted
- **Date:** 2026-08-22
- **Release:** 1.1.0

## Context

Focus Operating Framework published its independent v1.0.0 release on
2026-08-04. That release explicitly adopts Open Framework Commons v1.0.0 at
`a0f0d384e9010a65d1a21a324b4c912433d5e031` while correctly stating that
adoption did not itself place Focus in Commons scope.

Commons governance requires an explicit Charter amendment to add a scoped
product. Focus's adoption did not create membership automatically. Issue #7
therefore presented a separate steward choice: recognize Focus in Commons scope
or clarify that scoped products and other adopters are distinct sets.

## Decision

The steward chooses recognition. Recognize Focus Operating Framework as the
fifth independent product in Open Framework Commons scope. Update the complete
product list, shared-applicability test, ecosystem context, visual map, and
adoption links together.

Focus has equal provenance and importance with every other scoped product. It
remains independently governed and owns its purpose, audience, method,
terminology, evidence, releases, licensing, and implementation choices.

## Consequences

- Commons changes must now be evaluated for their effect on all five scoped
  products.
- Focus remains pinned to Commons v1.0.0 until Focus independently decides to
  adopt a later release.
- Commons v1.1.0 recognition does not amend Focus v1.0.0 or any other product.
- Adding another product still requires a separate Charter amendment and
  synchronized scope update.
